Memory Magic v1.0.0 — User Guide

A lightweight, native Windows utility for memory optimization, live hardware telemetry, startup control, and system cleanup.

1. Getting Started & System Tray

  • Main Dashboard: Launch Memory Magic from your Desktop or Start Menu shortcut to view real-time physical RAM, Commit Charge, Standby Cache, and Modified Page metrics.
  • On Close Behavior: Use the On Close dropdown in the top bar to choose whether clicking X asks each time, minimizes to the System Tray, or exits completely.
  • Run at Windows Startup: Enable Run at Windows Startup in the Memory Optimizer tab to launch Memory Magic quietly into your System Tray when you sign in to Windows.
  • Elevate (UAC): Standard mode handles safe working-set optimization. Click Elevate (UAC) when you want full kernel standby-list purges, all-user startup control, or Windows Optional Feature management.

2. Memory Optimizer

  • Safe Optimize: Gently trims idle working sets of running applications so unused pages are released without interrupting active work.
  • Deep Purge: Clears Standby, Modified, and System File Caches (requires Administrator privileges for full kernel purge).
  • Automatic Background Monitor: Enable the background watcher to automatically trigger optimization when RAM pressure crosses your chosen threshold (e.g., 80%) or on a periodic interval.
Tip: Hover over any control or click the ? contextual help icon to see a plain-English summary and impact note.

3. Floating Performance Bar

The compact Performance Bar displays live CPU, RAM, Network (Down/Up), Disk Active % / Free Space / Health, and Battery (on laptops).

  • Drag to Move: Click and drag anywhere on the bar (when unlocked) to place it wherever you want on your screen.
  • Lock / Pin Position: Click the padlock button on the right edge of the bar (or right-click → Lock Position) to freeze its screen coordinates and prevent accidental dragging.
  • Pin to Taskbar: Right-click the bar or tray icon and select Pin to Taskbar to snap it neatly above your Windows taskbar.
  • Always on Top: Keep the Performance Bar visible above full-screen or maximized windows.
  • Drive Selector: Click the ▾ button next to the disk readout to switch between All Drives or a specific drive letter.

4. Process Profiler & Startup Manager

  • Process Profiler: Inspect top memory-consuming processes (Working Set and Private Bytes) and trim an individual process safely.
  • Startup Manager: View and toggle programs configured to run at Windows startup across Registry Run keys and Startup folders.

5. Temp Cleaner & Windows Debloater

  • Temp Cleaner: Select safe temporary folders (User Temp, Windows Temp, Browser/Update caches) and clean reclaimed disk space with live progress.
  • Windows Debloater: Scan pre-installed UWP apps, Windows capabilities, and privacy/performance tweaks. Use Select Safe Bloatware & Tweaks for conservative recommendations.
Note: Before applying Debloater changes, Memory Magic prompts you to create a Windows System Restore Point so changes can be rolled back safely.

6. Uninstalling Memory Magic

Open Windows Settings → Apps → Installed apps, search for Memory Magic, and click Uninstall, or run Uninstall-MemoryMagic.cmd inside the installation folder.
